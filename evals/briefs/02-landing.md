# SaaS landing page

Marketing page for a B2B scheduling product: header, hero with two CTAs and social proof, trusted-by strip, how it works (3 steps), features bento, testimonials, pricing (3 plans, monthly/yearly), FAQ, CTA band, footer.

Deliverable: one self-contained HTML file (Tailwind v4 CDN + Lucide) unless the brief names a stack; realistic data; light + dark; must pass `scripts/verify_page.py` and `scripts/preflight.py`.
