# Operations dashboard

Admin dashboard for a 3-branch service business: sidebar, header with search, 6 KPIs with sparklines, a 12-week trend chart, a donut, a data table with sort/filter/bulk actions and loading/empty/error states, activity feed. Dark mode and RTL toggles.

Deliverable: one self-contained HTML file (Tailwind v4 CDN + Lucide) unless the brief names a stack; realistic data; light + dark; no console errors; nothing clipped at 375px or 1440px.
