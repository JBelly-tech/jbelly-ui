# Dense admin (operators)

Compact-density back-office for a keyboard-heavy operator: 38px table rows, command palette (Ctrl/Cmd+K), keyboard shortcuts sheet, inline edit on Enter/Esc, saved views, no decorative elements.

Deliverable: one self-contained HTML file (Tailwind v4 CDN + Lucide) unless the brief names a stack; realistic data; light + dark; must pass `scripts/verify_page.py` and `scripts/preflight.py`.
