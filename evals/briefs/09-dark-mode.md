# Dark-mode-first console

A monitoring console designed dark by default with a light toggle: status grid, incident list, log panel with monospace text, chart with 3 series; contrast at least 4.5:1 in both modes.

Deliverable: one self-contained HTML file (Tailwind v4 CDN + Lucide) unless the brief names a stack; realistic data; light + dark; must pass `scripts/verify_page.py` and `scripts/preflight.py`.
