# Empty-state-heavy app

A brand-new workspace where every list is empty: dashboard, projects, members, integrations. Each empty state has an icon chip, one sentence and a single action; a 3-step first-run checklist card.

Deliverable: one self-contained HTML file (Tailwind v4 CDN + Lucide) unless the brief names a stack; realistic data; light + dark; must pass `scripts/verify_page.py` and `scripts/preflight.py`.
