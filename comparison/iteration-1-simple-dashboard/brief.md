# Iteration 1 — simple dashboard (brief)

Build a single self-contained HTML file (Tailwind v4 browser CDN + Lucide) for the main dashboard screen of "Nutrio", a SaaS admin for a nutrition clinic in Amman: sidebar with navigation, header, page toolbar, 4 KPI cards, one chart, appointments table with status badges and row actions, activity list; dark mode and RTL toggles as a plus; realistic Arabic-Jordanian names; no commercial template code.
